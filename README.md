# 虫界战争 · 翡翠王冠

**[在线试玩](https://funct1ons.github.io/BugWar/)** · [GitHub 仓库](https://github.com/funct1ons/BugWar) · [问题反馈](https://github.com/funct1ons/BugWar/issues) · [贡献规范](CONTRIBUTING.md)

研究驱动的 **Bug War 2 非官方单机重制**。TypeScript + Phaser 3 + Vite，无后端、账户或运行时 CDN。18 张固定道路战场、4 个虫族、4 类建筑、虫族图鉴、多阵营 AI、孢子风暴、五星评级、12 项成就和自动存档。

> 原作地图、精确数值及 AI 内部规则未核实；这里是明确标注的重建与用户确认的轻量扩展，不宣称原版逐点复刻。未提取原作素材。[研究记录](docs/original-game-analysis.md)

## 轻量玩法扩展

- **18 关**：原 13 关编号和成绩保留，追加 5 张手工地图；新建筑及目标逐步介绍，不把所有机制塞进第一关。
- **自然生产上限 100**：生产巢、孵化巢达到 100 后停产，低于 100 恢复。增援可以超过 100，不截断、不丢兵；这是逐巢的自然产兵限制，不是全军人口上限。
- **友方据点自动中转**：点选可达目标，按固定道路选择几何距离最短的合法路径；所有中间据点必须己方，终点可以是任意阵营。途经友巢不合并驻军、不带走驻军、不重复计派兵。不穿越中立或敌方中间据点。
- **道路遭遇战**：同一道路上的敌对虫群相遇会短暂交战，双方攻防都生效，幸存虫群继续原命令。炮塔和风暴仍可打击在途虫群。
- **4 类建筑**：生产巢每秒 1 兵；孵化巢每秒 1.5 兵；风巢不产兵，离开时仅下一段道路速度 ×1.35；炮塔不产兵，按实时驻军增强火力。均自动生效，没有升级菜单。
- **两种目标**：歼灭所有敌方建筑与在途军队，或夺取清楚标记的核心据点立即取胜；当前目标显示在战场。
- **早期解锁**：敏捷族默认开放，完成敏捷族前 2 / 4 / 7 关分别解锁疾行 / 重甲 / 繁殖族。旧通关存档无需重新解锁。
- **保持简单**：每局选择一个种族，仍只有一个主动技能；没有混兵、训练资源、科技、装备、护送或生存倒计时。地图设计以休闲短局为目标，并非强制计时结束。

|虫族|速度|攻击|防御|特点|
|---|---:|---:|---:|---|
|敏捷|100|1|1|均衡基准|
|疾行|145|0.8|0.8|速度 +45%，攻击和防御各 −20%|
|重甲|72|1.35|1.3|速度 −28%，攻击 +35%、防御 +30%；没有额外炮塔抗性|

## 操作

|操作|作用|
|---|---|
|点击己方建筑，再点目标|沿合法道路攻击或增援，可经己方据点自动中转|
|从己方建筑拖向目标|同一套路径规则；选中多个来源时逐一校验|
|空地拖框 / Shift + 点击|多选 / 追加或移除选择|
|空格|全选己方建筑|
|底部 25 / 50 / 75 / 100%|派遣比例，默认 50%；按整数向下取整|
|A / 点击技能|满能量后选择区域施放孢子风暴|
|右键 / Esc|取消施法或选择；Esc 也可暂停|
|P / M|暂停继续 / 静音恢复|
|C / 虫族图鉴|查阅真实数值；战斗中自动暂停，关闭恢复此前状态|

不可达时提示 **无可用路径** 约 2 秒，不扣兵。混合多选中合法来源正常出兵，受阻来源保留兵力和选择。中间据点失守会中断后续自动路线；不会因为夺回它而偷偷恢复原命令。行军不能中途撤回或自由改道。

默认歼灭目标不要求占完中立建筑。最后一座己方建筑失守、但在途虫群尚存时不会立即失败。蓝为玩家，红／紫／金为互相敌对的电脑，中立为灰绿；归属文字和形状同时辅助辨识。

炮塔射程 200，火力节点为驻军 0 / 10 / 30 / 60：伤害 2 / 3 / 5 / 6，间隔 0.90 / 0.80 / 0.65 / 0.50 秒；节点间线性插值，60 后只有驻军防守继续增加。技能每秒回复 2 能量、100 消耗、半径 135，对区域内每个敌方建筑／虫群最多消灭 18 兵；不伤友军和中立建筑，不直接改变归属。

## Windows 最简单启动

已有 `dist/` 或下载了解压后的离线包时：

1. 双击 **`Start-Game.cmd`**。
2. 浏览器打开 `http://127.0.0.1:4173/`；保持命令窗口开启。
3. 退出时关闭窗口或按 Ctrl+C。

使用 Windows 自带 PowerShell 5.1，**无需 Node.js、Python、管理员权限或网络**。不要直接双击 `dist/index.html`；浏览器会限制 `file://` 模块及音频。首次交互后播放音乐。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Start-Game.ps1
# 4173 被占用时：
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Start-Game.ps1 -Port 4174
```

只监听本机 `127.0.0.1`。存档按浏览器和来源地址区分；更换端口／浏览器、切换本地与在线站点不会共享存档。

## 源码开发与打包

推荐 Node.js 24 LTS，最低 22.12。首次安装需要网络；运行成品不需要。

```powershell
npm.cmd ci
npm.cmd run dev
npm.cmd test
npm.cmd run build
npm.cmd run serve
# http://127.0.0.1:4173/

powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\package-release.ps1
# release\BugWar-VerdantCrown-Windows.zip
# 已验收的同一 dist 可加 -SkipBuild
```

`npm.cmd` 避开 Windows 对 npm.ps1 的执行策略限制。静态成品可部署在子目录；运行时资源全部同源、使用相对基础路径。

## 发布与验证

推送 `main` 后，`.github/workflows/pages.yml` 使用 Node 24 执行 `npm ci`、全部单测和生产构建，再发布 GitHub Pages。PR 只测试构建，不覆盖线上；发布权限仅部署任务持有。

```powershell
npm.cmd run test:browser
npm.cmd run test:lightweight
npm.cmd run test:roads
npm.cmd run test:offline
npm.cmd run test:playthrough
npm.cmd run test:onboarding
npm.cmd run test:art
npm.cmd run test:visual
npm.cmd run test:score
# 完成部署后，校验实际页面所加载 JS 与本地 dist 的 SHA256：
npm.cmd run test:online
```

浏览器脚本默认使用本机 Edge，可通过 `$env:EDGE_PATH` 指定兼容 Chromium。`test:online` 默认访问正式站；可用 `$env:GAME_URL` 指定另一地址。浏览器报告与截图在 `test-results/`，测试钩子仅在 `?test=1` 开启。

模拟回归与真实鼠标操作分开记录；合成的资源、归属和结算 fixture 不冒充自然通关。自动战役胜利不等于真人胜率，也不宣称 18 关人工试玩。详见 [验收报告](docs/test-report.md)。

## 美术、配乐与存档

原创「雨后灯火」四幕故事贯穿草甸、根林、湿地与琥珀庭；原 13 座守望巢之后追加归途挑战。**翡翠王冠是重新照亮归途的灯环。** 菜单「林地纪事」可随时查阅。

54 张自含 SVG：自然虫族封面、四种场景、四类建筑及四族六肢四帧虫兵的五阵营材质、徽章。阵营改变时切换主要材质纹理，不对整张图片简单染色。新增资源由 `scripts/generate-gameplay-art.cjs` 再生；旧资源生成器保持原样。[美术方向](docs/art-direction.md)

8 个原创核心主题使用合法 VSCO Community 真实管弦采样离线编曲；不是现场乐团录音。18 份分轨分别提供 OGG 与 MP3，八个既有 WAV 操作音效保留。五套战斗主题的三层在小节边界自适应混合；第 13 和 18 关使用终章主题。音乐导演只读战场，理解孵化巢、最终目的地和道路交战，不改变数值。[音频说明](docs/audio.md) · [素材许可](ASSET-LICENSES.md)

仍使用存档键 `bugwar-verdant-v1` 和版本 1。前三族原 13 关成绩、设置、累计统计及已获得成就保留；新增繁殖族与 14–18 关。原王冠／完美／三族成就保持原 13 关口径，不要求重刷或额外打新种族。禁用 localStorage 时使用会话存档并提示无法持久保存。

## 架构与边界

- `src/core/`：纯 TypeScript 固定步模拟、道路寻路、交战、技能与可见状态 AI。
- `src/data/`：18 关显式路网、图鉴、准备期和剧情。
- `src/game/`：Phaser 画面、选择、真实道路预览和效果；`src/main.ts`：HTML 菜单与 HUD。
- `src/audio/`：Web Audio 播放和只读音乐导演；`src/storage/`：校验存档。
- `public/`：完整离线资源；`scripts/`：生成、验收、服务及打包。

固定步长 0.05 秒，与画面帧率解耦。每批最多 36 只视觉虫兵、全场最多 1000 只精灵，仅限制表现数量，不丢逻辑兵力。道路是显式建筑连接，不支持自由地形寻路；装饰根须与水面不改变通行。面向鼠标 PC、16:9 最佳；其他比例留边，未专门适配触屏。[协作契约](docs/architecture.md)
