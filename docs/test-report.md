## 4. 性能与视觉复核

- 人工构造的压力场景：55个行军批次、逻辑约十万兵，实际渲染达到1000只可辨识昆虫上限；Phaser当次采样 **77.25 FPS**。
- 这只是本机Headless Edge的短时采样，不是低端设备、长期运行或所有显卡的帧率承诺。
- 虫兵上限只限制表现数量，不截断逻辑兵力。大数HUD改用K/M/B缩写。
- 主代理实际读取菜单、战役、普通战斗、大军、胜败和笔记本分辨率截图。根据截图修正底部数字被HUD遮挡、跨页面残留提示、徽章副标叠层；美术迭代增加锥形树根/树皮、叶脉和低对比地表细节，避免光滑管状根条与大片空渐变。
- 10张SVG通过XML、尺寸、四帧裁切边界及无外链验证。截图是成品运行画面，不是参考原作截图。

## 5. 音频实际输出与资源

12个真实44.1kHz/16-bit WAV全部成功解码（跨重载会话的资源并集），无失败文件。菜单34.286秒、战斗29.091秒循环；胜利9.9秒、失败11.031秒只播一次。

- 默认浏览器策略下，手势前AudioContext为`suspended`、没有活动音乐；真实点击后为`running`。
- 战斗循环标记正确；胜败不循环；切歌交叉淡化后只保留1个活动音乐源。
- 在压缩器后接只用于观测的AnalyserNode读取真实输出：播放RMS **0.04728**；静音平滑结束后RMS/peak **0**；恢复并同时播放7个不同音效后RMS **0.19759**、peak **0.68391**，有输出且本次未削波。
- 早期220ms静音检查窗口包含淡出历史，测试改为等待500ms再读取；不是用放宽峰值阈值掩盖故障。
- 独立PCM检查：音乐峰值约0.8912，音效0.4465–0.7079，削波样本0，循环文件首尾样本差0。首尾差0并不单独证明主观上绝对无接缝。
- 已验证真实解码、播放进度、输出非零、混音、静音/恢复、限流及循环配置；**本环境没有耳机/扬声器的人工主观试听**，不能声称做过专业听感或响度认证。

## 6. Windows无Node离线启动

`offline-report.json` 使用的不是Node静态服务器，而是 `Start-Game.ps1` 的原生TCP HTTP服务器：

- Headless Edge实际打开本地页面、加载全部资源、用鼠标派兵并占领中立巢。
- 44个响应，缺失资源/异常/外部请求均0；10个当前流程WAV解码，AudioContext运行。
- 另用真实TCP连接发送不完整请求头后主动断开，服务器仍返回下一请求200，验证EOF不再卡死。
- HTML与WAV的MIME/字节数正常，缺失资源返回404。服务器只监听127.0.0.1。

发布包由 `scripts/package-release.ps1` 生成；包含dist、启动脚本、README、许可、报告与验收快照，不包含第三方原作研究截图。已实际解压ZIP到 `release/解压 验证/`（中文与空格路径），再次使用包内PowerShell服务器完成相同浏览器占领/音频测试，44个响应、异常/缺失/外部请求均0；证据见 `docs/verification/offline-release-report.json`。运行时不需要Node、Python或联网，Node仅被开发验收驾驶器使用。解压后双击Start-Game.cmd即可。
