# 《翡翠王冠》：雨后灯火 / After the Rain

> 本文为本重制版原创世界观与第二版艺术总纲，不是 Bug War 2 原作设定或已核实剧情。玩法证据仍以 original-game-analysis.md 为准。

## 1. 故事：王冠不是一顶皇冠

古林的根须下，十三座守望巢曾以菌丝与巢灯相连。虫群把夜色中这一圈微光叫作「翡翠王冠」。它并不属于某位君主，而是每一条归途都能被照亮的约定。

一场漫长的暴雨冲断了根网。巢灯相继熄灭，迁徙的虫族为仅存的干燥巢域彼此争斗。敏捷族的苔翅行旅带着最后一枚种核出发：穿越晨露草甸、幽根林地、萤火湿地与琥珀荒庭，重新接通十三座失联的守望巢。

你不是征服整座森林的帝王，而是一位为虫群寻找归途的领航者。每一次占领，都是一盏巢灯重新亮起；炮塔是守望者留下的树脂鸣炮；孢子风暴借用的是根网中积蓄的微光。最终的王冠，是十三处灯火在树心重新汇合。

故事不改写胜负逻辑：仍须击败全部敌方建筑及在途部队；中立巢不要求全占。不要把叙事「重连」写成不存在的连线经济机制。

## 3. 美术总基调：可游玩的夜林博物志

关键词：**植物学蚀刻、树脂微光、古黄铜、层叠纸景、安静的史诗感**。

不要再做「亮绿渐变 + 大黑描边的卡通图标」。目标不是照片写实，也不是伪装手绘大作，而是高密度、克制、材料可信的原创插画：远看轮廓清楚，近看有叶脉、纤维、甲壳切面、磨损和雕刻。

### 调色与材料

- 墨松底色 `#0B1718`，深林 `#162C29`，雾青 `#3F6860`。
- 苔叶 `#789A7A`，古象牙 `#E7E0C2`，旧金 `#BF9D60`，树脂琥珀 `#B28B5A`。
- 玩家/敌军阵营辨识色可以更鲜明，但集中在旗、灯、细环与数字，而不是把整座建筑染成荧光色。
- 金属靠受光边、细划痕、暗面与少量高光表现，不靠整块黄色或无节制发光。木材有收细分叉与不规则生长纹，不画平行电缆。

### 构图与细节层级

1. 战场中心保持可读的中低对比地表；边缘形成不对称的近景叶片与根须框景，避免机械重复和左右镜像。
2. 用明暗地形台阶、断叶、泥土颗粒、细水纹、苔藓簇构成中景，不让中央只有一团空渐变。装饰仍不阻挡行军。
3. 背景细节不能比虫巢更锐利、更亮；不要在可玩节点下堆石块或粗枝。
4. 巢穴是贝壳/种荚/树根编织的守望建筑：屋顶有层次、入口有幽暗纵深与微暖灯光、底座有苔藓与材料接缝。炮塔是木骨架、树脂共鸣筒、旧铜箍，不是和巢穴相同的圆点。
5. 昆虫像博物图鉴里的甲虫与蚁：关节、胸背板、鞘翅、触角可信，取消可爱圆脸。小尺寸首先保证轮廓和六腿步态。
6. 主徽章是带种核的翡翠鞘翅甲虫与守望环，不是笑脸、粗线皇冠和剪贴画月桂。用细金属雕纹、透明树脂层、旧纸图鉴的严谨对称构成焦点。

### UI

更像一册被打开的野外图鉴，而不是网页后台：强标题层级、较少英文口号、留白、细框、安静材质；中文易读，低饱和底色配象牙文字和少量旧金。锁定关卡仍能看清地貌与标题。主要操作不能藏在装饰或长故事里。

故事入口应可随时阅读/关闭，不强制长过场；主菜单与章节文案要把「归途、守望巢、巢灯、种核」落到体验中。失败不是羞辱：给明确下一步与切换悠闲难度的选项，不清进度。

## 4. 配乐与音效

统一为**室内乐式的林地远征**：木笛/气息音、尼龙弦/拨弦、低弦/柔和持续音、稀疏木质打击与自然声纹。禁止芯片波形主旋律、尖锐音阶提示、大鼓轰炸或廉价循环电音。

核心动机「巢灯」：短、可记忆、留呼吸的上行与归落，在菜单、战斗、胜利和失败中变奏。菜单从孤独到微暖；战斗增加木质脉搏但不逼迫焦虑；胜利像灯火汇聚而非街机中奖；失败像暂时退潮，收束而不刺耳。保留真正的动态、空间与频段层次，不把所有声部填满全段。

真实WAV为可再生母带；优先提供适合网页加载的压缩衍生格式，并有可靠回退。默认音量不压过操作反馈；循环、瞬态、静音与异步切歌要继续实测。没有实际人工听音时必须承认，不用「电影级/录音棚级」等无依据宣传。

## 5. 难度修订准则

旧验收只要求每0.75秒思考的规划机器人能赢，这不代表新手体验。标准第二关只有1座初始巢、敌人2座，AI每1.5秒能同时规划多个进攻，对需要读提示、学派兵的新玩家过度苛刻。

- 标准前几关要容忍开局约8–12秒观察、每3–4秒才发一条指令、只用50/75%单巢出兵、不用技能与联合微操。
- 用更合理的初始驻军、可见的开局准备期、普通AI节奏及单轮进攻规模创造空间；不得背地改战斗公式、给玩家无限资源或伪造胜利。
- 战术难度保留有组织的快速决策；悠闲应真正更宽容。先控制标准前期的压迫感，再检查后期跳变。
- 至少用朴素、低频、延迟操作的脚本与真实浏览器第二关流程验证，不能只让玩家也调用高强度AI规划器来证明「能赢」。保留完整战役回归，记录实际成败，不承诺所有人都能一次通过。
