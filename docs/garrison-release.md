# 驻防与炮塔平衡调整

本次在轻量扩展版之上调整，不新增重型 RTS 系统。

## 战斗规则

- 所有有归属建筑的驻军防御 = 种族防御 × **1.2**；中立建筑和道路遭遇战不加成。
- 炮塔射程 **250**；驻军 0 / 10 / 30 / 60 时，伤害 **4 / 6 / 8 / 10**，间隔仍为 **0.9 / 0.8 / 0.65 / 0.5 秒**。节点间线性插值。
- 炮塔仍不产兵、每发只攻击一支在途敌军，没有范围伤害或专属装甲。60 人只限制火力，不限制驻军；增援不截断。
- 模拟、AI 路线风险估计、图鉴、操作手册共享规则常量。

## 避免僵局

增援可使非生产建筑积累超过 100 的守军。AI 的**额外进攻安全余量**按最多 100 人计算，避免双方因不断增长的保守余量无限等待；真实守军、种族防御、驻防加成、炮塔及路途损耗仍全部计入，不是把守军截断至 100。双方使用同一逻辑。

第 2 关己方 b 驻军 8 → 13，保留新手延迟、每 3–4 秒一次的低频操作余地；机器人没有增加技能、提高频率或使用未来预判。第 15 关起兵 72 → 73，保留疾行族在更强防守下的合法通关路线。没有增加通关预算、改变胜利条件或把超时算作通关。
