# 核心模拟规则与实际数值

以下是保守重建参数，不宣称是原版精确数值。接口以 architecture.md 为准；无升级、科技树或资源作弊。实现位于 src/core，纯 TypeScript。

## 种族与生产

|种族|行军速度（逻辑像素/秒）|攻击倍率|防御倍率|生产倍率|
|---|---:|---:|---:|---:|
|Agile|100|1|1|1|
|Fast|145|0.8|0.8|1|
|Strong|72|1.35|1.3|1|

生产巢每秒增加 `production × 种族生产倍率`，默认 production=1。中立建筑不生产。炮塔始终 production=0。没有游戏性的驻军上限；为数值安全，输入/生产计算防护上界为 10^12，非有限或负兵力归零。

## 行军、战斗、炮塔

- 每关显式配置固定无向道路 `roads`。派兵必须源与目标直接相邻，不因两者之间存在多跳通路而允许越点。缺少道路不回退任意直达。道路不随建筑归属、难度或虫族改变。
- dispatch 默认派出每个合法源建筑驻军的 50%，向下取整，至少 1 才出发；比例限制在 (0,1]。来源去重、逐项校验所有权与直接邻接；不能派向自身。混合多选仅合法来源扣兵，非法来源不增加事件或统计。
- 每批沿所选道路独立直线移动，行军途中不改目标。同一子步抵达按舰队 ID 递增结算；友军直接合流，**不自动中转**，下一段须重新下令。
- 攻方战力为数量 × 攻击，守方战力为驻军 × 防御（中立按 Agile）。差值为正则占领，剩余驻军=差值/攻方攻击；否则保留原所有者，驻军=负差值/守方防御。精确平局不占领。伤亡可为小数，派遣数量仍为整数。
- 非中立炮塔射程固定 200，只射击射程内首个存活敌方行军批次，不消耗驻军，不射建筑；无目标时保持就绪。火力由**实时驻军**分段线性插值（表见 `src/core/rules.ts` 的 `CANNON_FIREPOWER_NODES`）：0 人 2 伤害/0.90 秒、10 人 3/0.80、30 人 5/0.65、60 人及以上 6/0.50；节点之间线性插值，60 人为火力上限，更多驻军不加伤害也不缩短间隔。空塔仍按 0 人基准射击。
- 射击准备用 0–1 的充能记录，每步按“当前驻军对应间隔”推进，不保存固定秒数。临阵增减驻军会立即改变单发伤害与剩余充能速率，但保留已积累的进度，不重置冷却，也不免费补射一发。无目标时最多攒一发就绪射击。

## 能量与技能

所有已配置阵营每秒获得 2 能量，上限 100。满 100 才能施法，使用后清零。区域脉冲半径 135，对每个敌方非中立建筑及敌方批次分别消灭至多 18 单位；不伤友军、不占领、不伤中立建筑。技能可清空驻军，但所有权不变。AI 当前不自动施法。

## 统计与评星

- sent：玩家累计派出兵力。
- kills：玩家消灭的敌军兵力，不计中立驻军；含防守反杀、炮塔、技能，可为小数。
- captures：玩家占领建筑次数（含中立、夺回）。
- lost：玩家建筑被敌军占领的事件次数；夺回后再次丢失再次计数。**不是兵员伤亡**，生产巢和炮塔均计数。
- casualties：可选扩展字段，玩家累计兵员损失，含攻打中立的损耗，可为小数。
- skills：玩家施法次数。

评星重建公式：`score = max(0,time)/par + floor(max(0,lost))*0.5`。score ≤0.8 为5星，≤1.2为4星，≤1.8为3星，≤2.6为2星，其余1星。非法 par 使用120；非法 time/lost 使用保守惩罚。每丢一建筑直接影响评星，不再将 lost 当伤亡除以100。

## 确定性、胜负与输入

step 使用 0.05 秒固定子步并保存余数。忽略非有限/非正 dt；单次 dt 上限30秒，超出部分丢弃以避免异常调用阻塞。正常总时长相同的帧分割得到相同世界状态、事件与 AI 决策。每步顺序：生产、充能、炮塔射击、行军/抵达、胜负、AI。

玩家为1，AI为2–4。玩家没有建筑且没有在途部队即失败；所有敌方建筑及在途部队均消失才胜利；中立不要求占领。零驻军但仍有所有权的建筑仍算存活。结束后不再模拟。事件仅由 drainEvents 消费。

## AI 策略

- 思考间隔：easy=4秒、normal=2.7秒、hard=0.75秒。攻击余量系数分别为1.5、1.25、1.12；生产、行军和战斗无难度加成，无随机数。easy/normal每阵营每轮至多一个主攻目标，可由多巢协同；紧急增援先行且不受主攻目标上限限制，hard保留完整多目标规划。
- 战役配置开局观察准备期：normal各关为14/13/12/8/7/6/5/4/3/2/1/0/0秒，easy各加2秒，hard无准备期。准备期仅暂停敌方出令，双方生产与充能照常；到期首个固定步即可思考，不另加完整思考间隔。未配置的自定义地图默认为0。所有难度共享地图和初兵，第二关双方现均双巢；具体地图变化见 [平衡v2](balance-v2.md)。
- 每次从当前世界重新读取己方建筑，无威胁最低留守easy=10、normal=8、hard=5。按抵达时间及舰队 ID 顺序计算每次敌方抵达前的累计兵力缺口：`ceil(累计敌方有效战力/己方防御 - 此前已到友军有效数量 - 此刻前自身生产 + 4)`；取各时点需求的最大值作为驻防保留数。晚到友军不能抵消眼前威胁，远期攻击则允许扣除此前生产，不把远期全部敌兵直接冻结为当前驻防。
- 优先防守增援：逐个敌方抵达时点重新计算缺口，只从与目标直接相邻、可及时到达且有余量的源建筑派兵，目标余量4；增援自身路径的炮塔损耗也计入派出数，零有效抵达的增援不派遣。
- 目标排序考虑驻军/防御、距离与途中生产、类型战略价值。生产巢价值 `12+min(20,production*8)`；炮塔价值 `10+min(12,400范围内敌方建筑数*4)`；中立再减8成本。距离每秒增加2成本。
- 联合进攻仅纳入与目标直接相邻的己方来源，按距离从近到远纳入可用兵力。按实际抵达时间推演全部已知在途兵力及候选联合兵力，包含各次抵达间的生产、友军合流、多阵营加权交战及占领后生产归属。推演最终必须由己方占领且余兵至少 `3+目标当前驻军*(余量系数-1)*目标防御/己方攻击`，否则不发起。最后一个来源用整数二分减少过量派兵。
- 后方补给沿己方道路逐次前移：根据可见路网选择更靠近前沿的相邻己方目标，每次仍是新的单跳派兵，不让同一军队跨建筑自动中转；须保留防守预留并避免来回搬运。
- 已有在途部队推演可占领的目标不重复攻击；每次真实派遣后后续目标立即读取更新后的驻军和在途兵力。无凭空加兵。
- 路径炮塔估计：对每座当前可见的敌方非中立炮塔，将直线路径与半径200的圆相交，并将交弦截取到起终点之间；暴露秒数=截取长度/该批次种族速度。逐塔读取该塔**当前驻军**插值后的伤害与间隔，按 `伤害 × (1 + floor(暴露秒数/间隔))` 估计损耗，包含一次就绪射击；相切也保守计一次。多炮塔叠加，友军及中立炮塔不计。已有 fleets 使用当前位置到目标的**剩余**线段，不重复扣除已经走过的路段。估计函数与模拟共用 `src/core/rules.ts` 的同一张表，不再使用固定 2 伤害/0.75 秒常量。
- Arrival 同时保留原始 count 与 `effectiveCount=max(0,count-预计炮塔损耗)`；交战、合流和驻防推演只用 effectiveCount。联合方案的派遣及二分仍保留原始 count，每个候选数量重新计算 effectiveCount。可用兵力不足以穿过路径炮塔的来源不加入进攻；预计全灭的现有批次不再冒充一次成功占领。目标排序也纳入路径损耗。
- 局限：只根据可见当前状态规划，不能预测未来玩家派遣与技能。炮塔估计假设各炮塔就绪且对每批独立射击，不假定其它部队吸引炮火，也不预测途中炮塔被占领，所以可能高估多批并行时的损耗，但不会因此凭空增加实际伤害。联合来源不等待同步抵达，因此不是完美搜索策略。抵达推演为连续时间估计，实际模拟按0.05秒量化。

## 验证范围

Vitest 覆盖种族、生产/炮塔、中立与多方战斗、技能、胜负含在途、建筑损失与击杀语义、重复夺回、AI及时增援与迟到拒绝、在途去重、途中生产、联合攻击、目标价值、动态所有权、难度公平及规则化/不规则分步一致性；另覆盖炮塔路径截弦/多炮塔/种族速度/剩余路径、拒绝注定全灭的小批、Strong三难度等待生产积累后实际突破炮塔、不把晚到友军抵消短期威胁，以及远期威胁扣除生产。另覆盖炮塔驻军火力表（0/10/30/60 节点、中间线性插值、60 人封顶、负值/NaN 归基准）、实时增减驻军不重置冷却不刷立即射击、空塔基准火力、中立塔不射击、AI 损耗估计与共享函数一致及60驻军塔否决同一进攻，以及图鉴基准/成长表/已选炮塔实时伤害与间隔显示。另覆盖固定道路、非法越点、多选部分合法来源、AI后方单跳补给、13关拓扑／道路几何及图鉴真实数值；保留前3关18组低频单巢操作矩阵和准备期、难度节奏回归，以及独立美术资源回归。战役机器人预算已由600秒延长到900秒：炮塔驻军火力提升后，第10关easy的对称僵局需618.5秒才能突破（旧版518秒），胜负断言未改。当前全项目计数见 [test-report.md](test-report.md)；仅额外初兵搜索为按需扫描。存档格式与既有成绩未改变。
