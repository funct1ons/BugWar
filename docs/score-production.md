# 巢灯交响：离线实录管弦配乐制作与复核

## 交付与契约

本批次为八首原创核心曲、18 个逻辑音乐文件，每个同时交付 OGG 和 MP3，共 36 个音频文件。不是样板替换或运行时合成。唯一节拍真值为 `src/audio/score.ts`，生成器读取该文件；所有曲目为 4/4。源帧长为 `round(bars * 4 * 60 / bpm * 44100)`，立体声 44.1 kHz。同 cue 各层精确等长，不能分别重新对齐、归一化或随机起播。

## 作曲、动态与循环策略

八首独立八小节核心主题保存在生成器 `THEMES`，各 cue 有独立和声行进 `PROGRESS`。共享巢灯动机为级数 `0–2–4–8 / 7–4–2`，不是把同一个五音循环移调给所有地域。48 小节分成六个八小节段：主题呈示、回答与增配、逆行/反向音程静段、模进发展、巢灯再现、属功能回接。不同段落交接主奏乐器、调整动态、改变旋律方向和节奏密度。胜败有独立八小节主题、末段主和弦与留白，不把循环战斗曲截断充当结算。

- **base** 自身包含主题、低弦、内声部、呼应旋律，部分地域含竖琴，能单独作为完整平静配乐。
- **motion** 是独立短弓运动与竖琴/轻打击：根脉使用非均分六击节奏，琥珀/终章偏八分推进，草甸/沼泽较留白。
- **power** 加入根音／五度／三度型铜管和声支撑、选择性小号/长号、定音鼓与段落钹；不把它夸称独立对位反主题。大鼓只在特定段首或回接出现，不全程“预告片大鼓”。
- **定音鼓是有音高乐器**：五鼓共20份力度/RR录音分别测定主模态参考，先按目标音高选择最邻近鼓，再选力度和变体并重采样校准；目标折回 D2–A3 范围。测量采用攻击后0.12–0.65秒的 Hann 窗与模态频带峰值插值，不把最响的3:2上方模态误作基准。231份实际渲染变体的主模态最大误差约 **2.64 cents**。这是模态参考误差，不是人耳感知音准认证。
- 固定随机种子 `20260719`，每 cue 独立确定性种子。时值、落点、力度微扰；按力度选真实录制层，短弓/打击使用库内可用 round robin。连续乐器不冒称 true legato；不足时长的持续音采用录音内部交叉淡化延展，而非振荡器补音。
- 基于整段录音 RMS 做固定采样校准，随后保留谱面力度与段落动态；不对每个 stem 独立拉满。各 cue 所有 stem 共享一个增益，以各层绝对值包络和 4×过采样总线峰值中的更严格条件留出编码裕量。没有母带压限器或削波。
- 乐器释放越过循环终点时折回开头；立体声早反射/多抽头衰减空间也做环形卷回。声像固定，首尾不使用导致循环凹陷的整曲淡出。48 小节和声末段保持属功能，接回首段主功能。
- 胜败不环绕混响，最后五拍以上不再启动新音，末尾1.5秒收敛到零。真正的末旋律已在第7小节落到主音 D3（MIDI 50），第8小节只留释放；不是把主音安排在会被截止规则丢掉的位置。`endingChecks` 与回归测试直接断言实际事件。

## 再生

在项目根目录、PowerShell 5.1、Python 3.12：

```powershell
python -m pip install --target test-results/score-tools numpy==2.5.4 scipy==1.18.1 soundfile==0.14.0 imageio-ffmpeg==0.6.0
python scripts/generate-score.py
# 可选：独立目录全量再生，比较母带/36份解码PCM，实际测试损坏缓存拒绝：
python scripts/verify-score-production.py --regenerate
```

没有本机 ffmpeg 时使用 `imageio-ffmpeg` 的预编译 ffmpeg。编码 OGG 为 libvorbis quality 5（约 160 kbps，实际随内容变化），MP3 为 libmp3lame 160 kbps，显式 `-write_xing 1` 写 Xing/LAME gapless 信息。母带是 `test-results/score-masters/music-*.wav` 24-bit PCM。缓存固定源树后重新执行不重新下载采样；工具安装目录不加入发行。生成器只替换音乐、manifest，并删除旧 `music-battle.ogg` 与四个旧音乐 WAV；不写 src/tests、旧生成器或八个 sfx。

本次制作环境：Python 3.12.10、NumPy 2.5.4、SciPy 1.18.1、SoundFile 0.14.0、imageio-ffmpeg 0.6.0，FFmpeg 7.1 essentials。开发工具随后清理；运行成品不依赖它们。

完整事件（音高、起拍、时值、声部/旋律角色、力度、变体种子）、输入/输出 SHA、源帧数、解码帧数断言、定音鼓校准和终止检查、字节数、乐器清单及谱段均在 manifest。独立输出目录完整再生后，**18份WAV母带、36份解码PCM完全一致，18份MP3逐字节一致**。OGG编码器生成随机流序号及相应页面CRC，因此OGG文件SHA不同；逐页证明仅这两项不同，音频数据包、时间戳及解码PCM一致。不能声称36个容器SHA都能稳定重现，跨工具版本也不保证一致。

## 客观验证与限制

生成器对 **每个 OGG/MP3** 使用同一 ffmpeg 回解码为 float32 stereo，并严格断言解码帧数等于契约帧数；任何差异立即失败。MP3 padding 不靠裁切掩盖。还计算逐文件 RMS/采样峰/4×过采样峰/首尾跳变，OGG 与 MP3 分别叠加后复算总线峰、接缝、相邻样本差分第 99 百分位、末秒 RMS。`articulationChecks` 记录各乐器事件数量、音高数量、力度范围、采样数量与最近样本最大移调距离。真实Edge已另外检查全部36文件解码、gapless帧长、三层同钟、强度调度、结算自然播完及MP3回退，详见 [score-browser-report.json](verification/score-browser-report.json)；不推断其它浏览器也已通过。

独立子代理审查发现并要求返修：定音鼓曾被当无音高打击随机选鼓；结算末旋律未实际落主音；冷缓存来源未真正固定并验内容。三项已修复并全量重渲染，正式结果不是首轮样板：

- 36份音乐共 **60,783,213 bytes，约57.97 MiB**；最终渲染157.19秒，独立输出再生156.84秒。
- OGG全编4×峰值：menu .77457、meadow .73271、roots .80497、marsh .75465、amber .65636、finale .73062、victory .75367、defeat .77693。两格式全编最大约 **−1.8844 dBFS**，无削波。
- 循环全编首尾跳变：OGG .001874–.014784，MP3 .004743–.012193，均低于对应曲目的相邻样本差分第99百分位。这是边界没有显著异常的客观证据，不等于主观无缝。
- 胜利末秒RMS：OGG .00005203 / MP3 .00004956；失败末秒为0。两曲实际末旋律均为D3，最终小节无新攻击。
- 437份源文件逐份通过SHA-256及固定Git blob检查；实际破坏一次性缓存后重下正确文件，模拟错误下载也被拒绝。没有破坏正式源缓存。
- 完整证据：[score-production-report.json](verification/score-production-report.json) 与随包 `score-manifest.json`。最近采样最大移调仍有7半音的短弓高音，不是每音都独立录制。

**没有人工耳朵试听，不能声称专业试听、音乐会级管弦质感或最终艺术验收通过。** 这是原创确定性程序作曲与实录采样演奏，不是真人乐团新录音。库为免费社区版、层数和奏法有限；管乐不是真实多人圆号组，乐句连接不具备专用连奏过渡。定音鼓模态校准不能消除真实鼓膜的全部非谐性，也不能代替人耳音高判断；房间为多抽头早反射/衰减空间而非实测音乐厅 IR。重采样、录音持续段延展与静态声像可能留下可闻痕迹。4×过采样是客观 true-peak 近似，不是经过认证的播出响度测量。首尾样本不要求数值相同（连续声音本身有导数），应结合差分统计及真实重复播放审查。最终仍需要人类试听和浏览器听觉验收，不能以轨数或混响量替代。
