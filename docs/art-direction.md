# 雨后灯火：原创矢量资产第二版

遵循冻结总纲 `world-and-art-direction.md`。翡翠王冠是十三座守望巢的灯火约定，不是君王的冠冕；甲虫携带种核，巢灯意味着归途。没有新增连线经济或地形阻挡机制。

## 诊断与实际重绘

阅读了旧 menu.png、battle.png 及旧生成器。旧图的粗暗描边、重复边框叶片、四幕共用布局和皇冠拟人脸削弱材料感；大片径向亮绿也使战场接近模板背景。

本版重写 `public/art/generate_art.py`，不是替换调色板：

- 四幕分别使用晨露坡层、斜向暗铜根木、蓝灰沉积水纹、烟金树脂干叶。根木锚点、叶群位置、坡线和局部叙事物不同，不镜像铺边。中景有断续沉积线、苔簇、枯叶和低对比颗粒。
- 守望巢为三片非等形种荚屋顶，细壳肋、木根弧梁、绑绳、深入口与内暖光、悬灯和两级台阶；不是圆形黑线图标。
- 炮塔为三角木骨架、树脂共鸣筒、双铜箍、开口暗喉和铆钉。材料保留本色，交由主场景旗帜/光圈辨阵营。
- 三族均为六足关节、触角、胸板、鞘翅或分节腹部；四步态，头朝上；无拟人笑脸。重甲族加肩板，疾行族收窄腰节。
- 徽章使用金属蚀刻守望环、十三灯座、翡翠鞘翅甲虫与半透明种核；移除皇冠与月桂模板。

艺术语言是植物学细线、树脂渐变、古黄铜受光边和纸景式坡层。没有使用滤镜掩盖几何；没有远程图片、字体或他人图像。属于标准库生成的原创矢量插画，不声称电影级或人工手绘。

## 自动使用的十张契约

| 文件 | 尺寸 |
|---|---|
| background-{meadow,roots,marsh,amber}.svg | 各1600×900 |
| nest.svg / cannon.svg | 各160×160 |
| bug-{agile,fast,strong}.svg | 各96×32，横排四帧，各24×32 |
| emblem.svg | 256×256 |

节点范围 x120..1480、y235..710 使用低对比细节，强轮廓留在边缘；顶部130和底部792起为暗化UI区。背景装饰不是实际障碍。

## 再生与验证

- `python public/art/generate_art.py`：再生十图和 `validation.txt`。验证XML、width/height/viewBox、全部本地渐变引用、无href及外链、四帧平移及userSpaceOnUse硬裁剪。
- `node scripts/art-preview.cjs`：使用现有Playwright与系统Edge，无持久服务，解码十图并生成 `test-results/art-sheet.png` 接触表（交付快照见 `docs/screenshots/art-sheet.png`）；canvas检查每帧左右边缘透明。
- 实际首轮浏览器检查发现足端触及单元最外像素，已缩进足端再生成；第二轮通过全部帧边缘透明检查。主代理已读取接触表复核，随后补充中景沉积苔簇以避免中央仅有渐变。
- 接触表与预览脚本是辅助验收材料，不参与游戏主表现。未添加副装饰资源依赖。

边界：此处记录的是资产制作与文件级浏览器渲染，不以接触表冒充游戏实机验收。完整UI叠合、实际缩放、阵营辨识、压力场景与公开Pages另见 `docs/test-report.md` 的本轮验收。
