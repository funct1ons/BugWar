## 视觉语言与构图
深墨绿轮廓搭配暖金、灰绿甲壳与手绘式曲线。背景采用径向明暗层次、土壤细线、边缘植物群落、刻纹石块和微小露光；非随机散贴图。主要枝叶、石块和装饰沿外围组织，中央清场保留低对比纹理，避免遮蔽 x=120…1480、y=235…710 的战斗节点。少量根须在侧边形成自然框景。顶部约 130px 与底部 790px 以下压暗用于叠加 UI，背景本身不包含文字或交互控件。

建筑不使用圆形节点代替实体：巢为不规则堆土拱体，炮塔为纵向枝干支撑与明显炮口。虫体统一头朝上、三对六足；四帧通过两侧足端交错改变完成步态。帧序 0→1→2→3 循环，每帧 24×32；建议 8–12 fps。轻甲虫、蚁、角甲虫的体节和外轮廓不同。

建筑和单位使用中性白绿／褐金，支持 Phaser `setTint` 乘色染阵营；染色会同时影响轮廓与高光，建议使用偏亮阵营色。单位 0.54–0.64 scale 下细节会缩小，保留约 1–2.4px 原始轮廓作为辨识依据；实际设备像素比下的效果需在游戏内确认。

## 加载与限制
- 背景、建筑、徽章可用 Phaser SVG loader；四个单位帧需将整张 SVG 栅格化后按 `frameWidth: 24, frameHeight: 32` 切片，不要把整张图当成单帧。
- 单位每个单元有独立 24×32 clipPath，避免腿或触角串入邻帧。透明画布不带实色矩形。
- 所有 SVG 仅使用路径、椭圆、渐变、组变换和裁切；无远端图片、字体、脚本、滤镜或外链。光晕通过渐变实现。
- 徽章静态光晕可作为菜单 focus 的基础；运行时可对整个徽章轻微放大或调透明度，本交付不修改游戏代码。
- 背景固定 16:9，非无缝平铺。四帧均为朝上，不包含转向贴图。主集成已完成Edge/Phaser实机截图复核，精选画面见 `docs/screenshots/`；根据截图进一步增加树皮、叶脉与地表细节，详情见 `public/art/iteration-notes.txt`。

## 来源与可复现验证
全部几何图形为本任务原创，以 `public/art/generate_art.py` 手工构图并程序化输出；无第三方图像、字体或原作素材。

在项目根目录运行：

```sh
python public/art/generate_art.py
```

脚本会重新输出十张 SVG，并使用 Python 标准库 XML 解析所有资源，断言 width/height/viewBox、无外链属性，以及三个精灵图各四帧的平移坐标与裁切矩形。结果写入 `public/art/validation.txt`。此检查验证格式和硬裁切边界，不代替浏览器／Phaser 像素级渲染验收。
