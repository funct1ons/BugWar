# 日光花园：正式美术方向

本版以用户确认的第二次封面重绘为准：**自然虫族、蓝轻红重、明亮微观花园与清楚的策略信息**。它替代此前的暗色「夜林博物志」，不是在旧画面上整体提亮。

## 统一视觉语言

- 暖白、浅叶绿与天蓝的环境；主体使用干净渐变、柔和接触影、局部厚边和简化材质。不是写实渲染或电影级原画。
- 封面左侧留给标题与真实操作，右侧为蓝方持叶刃／小盾的前锋，与红方持斧的重甲守卫。自然头胸腹、触角与六肢是角色基础；不再把人形板甲骑士加上触角。
- 两位封面角色是叙事代表，不表示新增英雄操作、装备、单挑或成长系统。
- 战场同样使用暖亮光照。草甸、根林、湿地、琥珀庭院各有地表与边缘植物差异，但不会因章节变成灰暗夜景。水面、根须与背景土路均不阻挡行军。
- 生产巢为花瓣／种荚结构，炮塔为不同轮廓的木石鸣炮；轮廓、材质与所有权要同时可读。

## 阵营：大色块与形状双重辨识

| 所有者 | 主色 | 主要含义 |
| --- | --- | --- |
| 0 | `#92A18B` | 中立，空心环 |
| 1 | `#327FC1` | 己方蓝，圆形／勾 |
| 2 | `#C85F48` | 红方，菱形 |
| 3 | `#8B70BA` | 紫方，三角形 |
| 4 | `#C49336` | 金方，方形 |

建筑屋顶／炮壳、虫兵甲壳使用按所有者绘制的独立 SVG 变体，而非只用小旗、细圈，也不把整张纹理统一染色。木石、眼睛、关节和入口保留材质。占领后必须切换真实纹理、文字与形状标记。

数字牌浅底深字，选中与路线采用醒目的蓝色。场上建筑类型和归属文字、HUD阵营标记继续提供冗余信息。阵营不是种族：四种族均可属于不同所有者。

## 正式资源合同

| 文件 | 尺寸与用途 |
| --- | --- |
| `cover.svg` | 1600×900，获批封面插画，无UI或样张水印 |
| `background-{meadow,roots,marsh,amber}.svg` | 各1600×900，四幕战场 |
| `{nest,cannon,hatchery,wind}-{0..4}.svg` | 各160×160，五种所有权变体 |
| `bug-{agile,fast,strong,brood}-{0..4}.svg` | 各96×32，横排四帧，各24×32，头向上 |
| `{nest,cannon,hatchery,wind}.svg` | 中立变体的兼容入口 |
| `bug-{agile,fast,strong,brood}.svg` | 蓝方变体的UI入口，显示时裁为单帧 |
| `emblem.svg` | 256×256，种核甲虫与十三灯环 |

共54张SVG（原36张保持，新增18张）。孵化巢以卵囊／巢瓣表现快速产兵，风巢以叶轮／气流表现下一路段加速；繁殖族使用独立轮廓的腹部与六肢步态，不是额外战斗职业。每个文件自含、无远程图像／字体／脚本。单位帧边缘保持透明。战场保持1600×900逻辑坐标，顶部与底部HUD不改变地图和输入规则。

## 源文件与再生

```powershell
python public/art/generate_art.py
node scripts/generate-cover.cjs
node scripts/generate-gameplay-art.cjs
npm.cmd run test:art
```

封面生成器独立保存获批插画曲线，不依赖已删除的设计预览目录。旧正式资源由Python标准库生成，新增繁殖族／孵化巢／风巢由独立Node脚本生成；游戏运行不需要Python、Node或绘图工具。

`test:art`使用系统Edge解码正式SVG、验证所有单位变体的帧边界，并生成临时接触表。精选接触表在 `docs/screenshots/art-sheet.png`。正式游戏叠合、18关布局、真实占领与回归结果见 [测试报告](test-report.md)，不能用接触表代替实机检查。

## 制作与验收边界

所有插画均为本项目原创矢量曲线／程序绘制，没有采购、拼贴或分发检索中的第三方角色。它不是专业画师委托或图像生成接口的输出，也不以「电影级」「真实手绘」宣传。技术解码和布局检查不等于主观美术认证。

原有36张美术及音频继续保留；当前轻量玩法扩展同时增加新类型美术，不改变旧存档键与版本。已确认的临时封面和旧实战提案在正式资源提升、验收后删除，保留正式可复现源文件与必要成品截图。
