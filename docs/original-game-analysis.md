## 2. 完整玩法说明

**确认（网页/同期评测）**：单人即时策略。指挥一种昆虫种族，控制建筑生产虫群、调兵占领中立和敌方建筑，最终消灭敌方势力。生产巢（Spawn）持续按秒生产；炮塔（Cannon）不生产，但对来袭虫群发射炮弹；两者均可无限驻军。友方多巢可联合派兵。能量满后可区域施法。13关逐关推进，通关获得1–5星；速度和丢失建筑影响评级。初始只开放 Agile，用其完成战役后开放 Fast 和 Strong；有12项成就鼓励重玩。

**合理推断**：虫群在源巢与目标间行进，敌我抵达时发生兵力消耗，归属随占领变色；兵力与距离构成扩张/防守的时机取舍。原先网页研究未确认具体路径、抵达批次和驻军战斗公式；道路约束后经用户反馈补充，本版采用上述已确认的逐巢方案。

## 3. 规则与数值清单

|机制|证据状态|本项目保守实现|
|---|---|---|
|生产巢持续增长|确认“every second”，每秒数量未知|基础每秒1单位，可由关卡设定；小数累积、显示整数|
|容量|同期评测称无限|没有玩法人口上限；仅JS安全数值保护|
|派兵操作|确认单选/拖框/源→目标|点击源再点目标、拖拽源到目标、拖框、Shift追加、空格全选|
|派兵比例|未知（不采用搜索摘要的“Shift半兵”）|默认50%，可选25/50/75/100%；属于重制便利功能|
|固定道路|用户指出原作约束；逐巢方案经用户明确选择|只有直接相邻来源可派兵；13张路网原创，不跨巢自动中转|
|友军增援|合理推断|沿直接道路抵达当前友军建筑叠加兵力，后续一段需重新下令|
|行军撤回/改道|未知|不支持中途撤回/改道，避免无依据扩展|
|行军交战|未知|道路不拦截，抵达建筑结算；炮塔可截击行军|
|战斗/占领|结果层面确认，公式未知|按种族攻防权重减驻军，剩余攻击兵占领；同时抵达以固定逻辑步和稳定顺序结算|
|炮塔|确认不生产、能射来袭虫群|固定射程/间隔/伤害的自动防御；具体数值为重建|
|胜负|占领/压倒对手的描述|消灭全部敌方建筑及在途军队获胜；己方建筑及军队皆无则失败；不要求占完中立|
|升级、建筑转换|无证据|不加入建筑升级、科技树、变塔|

实际数值权威在 `src/core/`，不是声称原版参数。固定时间步与逻辑/表现分离保证多批次、多阵营及大兵力一致性。

## 4. 种族与建筑

确认名称 **Agile / Fast / Strong**，但未确认对应昆虫物种、速度、攻击、防御或生产倍率。重制以敏捷甲虫/疾行蚁/重甲虫表现，设定Agile均衡、Fast速度优先/战斗弱、Strong慢速/攻防强。这些是基于名称的保守设计，不是已测原版属性。初始种族及通关解锁条件忠实同期描述。

两类建筑有不同战略价值：生产巢提供经济；炮塔是不能自给的防线，需要后方增援。没有空巢自动中立化，没有未经确认的升级/转换系统。

## 5. 技能系统

**确认**：满能量条，按A或点条，点击区域施法。**未确认**：充能来源、实际效果、范围/持续/友伤/伤害/冷却。有低可信转载提到龙卷风，不能定论。本版采用「孢子风暴」视觉：满100能量一次性消耗，范围内削减敌军，友军免伤；时间及战斗充能等精确规则由核心实现记录。这是明确标注的重建，不是原版已证实魔法。取消目标使用Esc或右键。

## 6. AI与关卡

原版AI规则未取得源代码/可控实测。只可推断会扩张并进攻。重制效用AI主动比较中立价值、敌巢弱点、距离、在途援军、威胁和留守需求；仅从直接道路邻接来源进攻／防守，后方逐次沿己方道路单跳补给，按需联合进攻，不随机盲攻、不额外生成资源。难度改变反应时间、目标/防御权重。

关卡数忠实13关；末关参考“The Final Level”。**13张具体地图未能验证，均为原创重建，不冒称像素级原图**。按基础扩张→炮塔→分兵→多阵营→大地图联合战的难度曲线设计。四种生态与不同几何布局避免改数字凑关。1–5星参考速度+丢巢，但阈值/公式重建。12项成就主题同样原创，不冒称原版奖杯内容。

## 8. 与原版差异及验收边界

保持：虫巢争夺、单位自动生产、两种建筑、鼠标多巢调兵、三种族及解锁、13关、1–5星、满能量A施法、完整单机流程。

重建：数值、地图坐标／固定路网与初始驻军、AI内部策略、物种造型、魔法效果/充能、评分阈值、成就内容、全部视听资产。现代化：高清有机手绘风格、宽屏/缩放、派兵比例选择、暂停、音量设置、持久化存档。

仍值得后续核实：在合法可玩的原版或完整录像中，受控记录派兵前后数量、静止生产与能量变化、相同数量异族交战、炮塔射击周期、每关开局。补齐后可只修改配置/规则而不重写渲染。当前证据只支持“研究驱动的忠实框架重制”，不支持“原版全部机制精确还原”的宣传。
