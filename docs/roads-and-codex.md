# 固定道路、多跳命令与虫族图鉴

本页描述当前用户确认的轻量扩展。原先「仅相邻派兵、到站必须重发」已被合法友方多跳命令替代；历史测试截图或平衡记录不能作为现行规则。固定道路不变成自由地形寻路，也不宣称是原作 18 张地图逐点复刻。

## 命令合法性

1. 建筑只能沿 `LevelConfig.roads` 显式声明的无向道路行军；没有路就不飞过去。
2. 源建筑必须己方。所有**中间据点必须己方**，终点可己方／中立／敌方。选择总几何距离最短的合法路径，同长时确定性择序。
3. 一次命令可走多段真实道路。途中同一批虫群自动通过己方据点，不合并该据点驻军、不带走新兵、不重复计算派兵统计。
4. 友军终点正常增援，可超过自然生产上限 100；中间巢不会因为经过而出现人口加减。
5. 多选逐源验证：可达来源扣除派出兵力，受阻来源原样保留兵力及选择。全部受阻时不生成派兵、不改统计。两种情况均提示「无可用路径」约两秒。
6. 中途失守不算合法通行：到达该节点正常交战并停止后续自动路线，不能因当次夺回而继续原命令。更后方的敌对中间节点也不能偷偷穿越。
7. 玩家与 AI 使用同一核心寻路和 dispatch；没有 AI 跨路、透支驻军或生产加成。

路径由 `src/core/roads.ts::findDispatchPath` 计算，模拟与路网预览共用。`hasRoad` 仍只判断一条真实直接边，不能把「可经己方中转」误画成一条新道路。

## 道路相遇

敌对批次在同一道路相遇会自动短暂交锋，双方攻击和防御同时参与结算；等量同族没有先手优势。幸存部队继续原路线，增援可继续参与交锋。不是技能、没有新的微操菜单。炮塔和风暴仍攻击实际在途虫群。不同道路仅在画面交叉不产生虚构遭遇点。

## 路网与画面

18 关各自保留显式手工路网，前 13 个编号不变；新增 14–18 关沿用存档进度。道路端点合法、无自环与重复、整图连通；道路不穿越无关建筑、不因选择种族或难度而改变。关卡几何和可读性由 `tests/roads-levels.test.ts` 与浏览器布局检查共同验证。

战场常显真实道路；选中和拖拽时可达终点有反馈，悬停显示到该目标的实际各段路线。不可达目标不画跨图虚线。战役缩略图直接读取同一 `roads`，不按建筑数组顺序连假线。核心目标有单独标记及明确文字，不能与普通中立奖励混淆。

## 图鉴

菜单、战役、战场均能打开图鉴；未解锁种族可查阅，但阅读不会解锁。

- **4 虫族**：敏捷、疾行、重甲、繁殖。显示真实速度、攻击、防御、生产倍率、优势代价和早期解锁条件；繁殖族说明首次中立生产类据点 +8 及攻防各 −10%。重甲没有额外炮击抗性。
- **4 建筑**：生产巢 1 兵／秒、孵化巢 1.5 兵／秒，均自然产至 100；风巢仅下一段速度 ×1.35、不会跨段叠加；炮塔不生产，实时驻军火力成长仍按共享表显示。
- **指挥**：友方中间节点、多选受阻、自然停产和超额增援、道路遭遇、风暴与歼灭／核心两类胜利条件。

数值由 `RACES`、`BATTLE_RULES`、`CANNON_FIREPOWER_NODES` 生成，不复制另一套平衡表。炮塔选中面板读取当时实际驻军；驻军改变时，伤害与间隔显示一起更新。

图鉴自动暂停战斗，切条目不反复重写暂停快照。关闭时恢复此前运行状态；从已有暂停菜单进入则仍保持暂停。P 在图鉴内不应误穿透，Esc 关闭图鉴而不触发场景操作。弹窗支持键盘导航，1280／1366／1600 宽度内容可达。

## 验证

- `npm test`：寻路合法性、最短路、部分多选、路线中断、固定步一致性、人口边界、道路遭遇、四族／四建筑与旧存档。
- `npm run test:roads`：真实鼠标与拖拽、精确无路提示、友方多跳、部分受阻、18 关真实路网和缩略图、炮塔面板与完整图鉴暂停行为。
- `npm run test:lightweight`：新增规则受控 fixture 与真实行军、旧存档 reload、18 关 HUD、三尺寸战役滚动和核心目标结算。
- `npm run test:online`：正式页面无调试接口，检查已部署新图鉴、18 关、四族、实际鼠标占领及构建哈希。

受控 fixture 与真实自然操作分开记录。具体执行结果和限制见 [test-report.md](test-report.md)。
