# 固定道路与虫族图鉴

## 本轮依据与发布边界

用户指出旧实现允许任意两巢直接派兵，缺少道路限制，削弱据点战略价值；同时缺少虫类、巢穴及炮塔的功能说明。用户明确选择**方案一：逐巢派兵**。本轮据此修正玩法，并补充图鉴，而不是只绘制装饰连线。

本道路规则是本次用户确认的重制方案。尚未独立实测原版每张地图和自动中转细节，不把本方案或13张路网冒称原版逐点还原。上一轮音画版本已部署；本轮道路与图鉴改动在获得新授权前不推送、不部署。

## 规则契约

- 每关具有固定、无向的道路集合，每条道路连接两个建筑ID。道路不因所有者、虫族或难度变化。
- 一次派兵只允许源与目标**直接相邻**。两点之间即使存在经过其他巢穴的通路，也不能直接下令跨越。
- 抵达己方建筑只增加驻军，不自动开始下一段行军；继续前进须再次下令。途经敌方或中立建筑也不能跳过占领。
- 多选按来源逐一校验：只有与目标直接相邻的己方来源出兵，其余保留全部兵力。无合法来源不扣兵，不增加派兵统计，也不生成派兵事件。
- 玩家和所有AI共用同一合法性检查，不能靠直接调用模拟接口绕过道路。AI可将后方兵力逐次调往相邻己方建筑，但不享有自动穿越据点的能力。
- 行军沿所选道路的直线段移动，不支持中途撤回、改道或在道路上互相拦截。炮塔仍可攻击射程内的敌方行军批次。
- 道路不是经济管线，不会自动输兵、加生产、共享驻军或改变建筑种类。装饰根须、水面不是可自由行走的新路径。
- 胜负仍计算全部敌方建筑和在途军队，不要求占完所有中立据点。

## 关卡与战场表现

13关分别维护显式路网；要求端点合法、无自环、无重复边、整图连通、道路不穿过无关建筑，且不同关卡具有不同的岔路与关隘结构。道路数为建筑数至建筑数+3，禁止全连接；与第三座建筑中心至少相距160，与不共端点道路至少相距24（世界坐标单位）。炮塔至少连接两路，至少三关设有四路枢纽。

本轮不改坐标、初兵、所有权、生产率或准备期。首关与第三关在低频回归中暴露绕后失守后，仅删改道路修正，不用加兵或降低断言掩盖。

战场常显全部道路。选择建筑时强调相邻道路与合法目标；拖拽预览不能画出不存在的行军线。无路操作给予明确提示。战役缩略图读取同一关卡道路数据，不再把建筑数组顺序画成伪路网。

## 图鉴内容

- **族群**：敏捷、疾行、重甲三族的真实行军速度、攻防及生产倍率，优劣、使用建议和解锁条件。尚未解锁的族群仍可查阅，不增加虚构的特殊克制。
- **建筑**：生产巢默认生产、地图自定义生产与归属；炮塔不生产，需要增援，介绍实际射程、空塔基准伤害与间隔、**驻军火力成长表**（0/10/30/60 人分段线性插值、60 人上限）以及战斗中已选炮塔的实时伤害、间隔与驻军加成。
- **指挥**：道路与逐巢推进、25/50/75/100%整数派兵、联合进攻和友方增援；孢子风暴的能量、范围、伤害和不改变所有权等限制；阵营和胜负条件。
- 数值引用 `src/core/types.ts` 的 `RACES` 与 `src/core/rules.ts` 的 `BATTLE_RULES`／`CANNON_FIREPOWER_NODES`，模拟、AI、图鉴与选中面板共用同一纯函数 `cannonFirepower`，不另写一套会失配的数值。
- 沿用既有SVG，虫兵图只显示四帧表中的单帧；不增加运行时外链资源。
- 菜单、战役及战场可进入；战斗中打开暂停，切换分类/条目不改变暂停快照，关闭恢复打开前状态。原本已经暂停的战斗仍保持暂停。

## 不变范围

音频播放引擎、音乐导演、36份音乐、8个音效及既有美术资产不因本轮改动重做。存档键仍为 `bugwar-verdant-v1`、版本仍为1，既有解锁、最佳成绩、成就与设置保留。道路由关卡配置加载，不写入旧存档，不要求清空进度。

## 验收方法

1. 单测检查无向邻接、非法跨越、混合来源、玩家/AI一致、后方逐巢补给及确定性；全13关验证拓扑和几何。
2. 保留195场五策略战役矩阵及前3关18组低频单巢指令组合。低频策略也必须检查道路，只读当前可见状态，不增加技能或高频规划来掩盖难度。
3. 真实Edge检查道路输入、提示、图鉴分类与数值、暂停恢复、Esc、键盘和三种屏幕尺寸；合成fixture与自然通关分别记录。
4. 重跑通用交互、美术/布局、真实时间首关及低频第二关，并从原生PowerShell启动器与中文空格路径解压包检查离线资源。
5. 实际执行结果和未覆盖边界见 [本轮验收报告](test-report.md)。自动化胜利不是13关人工通关，也不是人类胜率。
